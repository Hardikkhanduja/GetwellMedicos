# Getwell Medicos

Official website for **Getwell Medicos** — a licensed pharmacy located at Booth No. 13, Sector 35C, Chandigarh.

🔗 **Repo:** [github.com/Hardikkhanduja/GetwellMedicos](https://github.com/Hardikkhanduja/GetwellMedicos.git)

---

## Features

- Responsive design — works on all screen sizes (360px and above)
- Prescription upload with WhatsApp notification to the owner
- Google Maps embed with exact shop location
- Services, medicine categories, contact info & working hours
- Floating WhatsApp button for instant contact

## Tech Stack

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) — animations

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
